# Video Bulk Downloader - Landing Site

This is the landing page for the Video Bulk Downloader project. A clean, modern website showcasing the tool with setup instructions and features.

## Deployment

This site is ready to deploy to Vercel with zero configuration.

### Deploy to Vercel

```bash
npm install -g vercel
vercel
```

Or connect your GitHub repo to Vercel and it will auto-deploy on every push.

## Local development

Simply open `index.html` in your browser, or serve it locally:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js
npx http-server
```

Then visit `http://localhost:8000`

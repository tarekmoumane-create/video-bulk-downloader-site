How it works

Add videos

Paste links directly, upload a CSV file, or connect a Google Sheet with video URLs.

Download

Click one button. The app downloads all videos in the highest quality available.

Save

Videos are saved to ~/Downloads/Videos with creator names and metadata.

Share (optional)

Optionally upload everything to Google Drive with one click.

Get started in 2 minutes

What you need

  • Python 3.7 or later
  • A terminal (or command prompt)
  • 5 minutes of your time

Optional: If you want to save videos to Google Drive, you'll need to set up rclone once. We have clear instructions for that.

Installation

git clone https://github.com/tarekmoumane/video-bulk-downloader.git cd video-bulk-downloader pip install requests openpyxl python -m pip install -U yt-dlp python3 server.py

Then open http://127.0.0.1:8765 in your browser.

Video Bulk Downloader

Download videos from TikTok, Instagram, and YouTube in bulk. No watermarks, full quality. Free. Open source. Runs locally on your machine.

Download

Features

  • Download from TikTok, Instagram, and YouTube
  • Paste links, upload CSV/Excel, or connect Google Sheets
  • Full quality, no watermarks
  • 100% private - runs on your computer
  • Optional: Save to Google Drive automatically
  • Organize videos by date

Get started

You need Python 3.7 or later.

git clone https://github.com/tarekmoumane/video-bulk-downloader.git
cd video-bulk-downloader
pip install requests openpyxl
python -m pip install -U yt-dlp
python3 server.py

Then open http://127.0.0.1:8765 in your browser.

How it works

  1. Add videos: Paste links, upload a file, or connect a Google Sheet
  2. Download: Click one button to download all videos
  3. Get files: Videos saved to ~/Downloads/Videos/
  4. Optional: Upload to Google Drive with one click

Google Drive setup (optional)

If you want to save downloads to Google Drive, install and set up rclone once:

brew install rclone
rclone config

# Choose 'n' for new remote
# Name it: gdrive
# Choose option 15 (Google Drive)
# Follow the prompts to authorize
# Done!
